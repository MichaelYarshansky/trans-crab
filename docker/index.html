Trans-Crab 🦀

Transcribes your Google Meet and Zoom calls, then saves the text as a file.

version __VERSION__
Download extension (.zip) Unpacked Chrome extension · Manifest V3

Features

  • Real-time speech-to-text, with Hebrew support
  • Works on both Google Meet and Zoom
  • Single-button operation to start and stop
  • Synchronized timer reflecting true recording duration
  • Transcript downloads automatically as a text file

Install

  1. Download and unzip the archive above.
  2. Open chrome://extensions/ and enable Developer mode.
  3. Click Load unpacked and select the unzipped folder.
  4. Pin Trans-Crab from the 🧩 puzzle icon in your toolbar.

Use

  1. Join a Google Meet or Zoom call in your browser.
  2. Click the Trans-Crab 🦀 icon in the toolbar.
  3. Hit Start Transcribing — the timer begins.
  4. Hit stop when done; the transcript downloads as .txt.
